# Bongoboltu AI

A bilingual (Bangla + English) educational chatbot prototype exploring the life, speeches and historical legacy of Sheikh Mujibur Rahman.

## Run locally
Open `index.html` in a browser. No build step or API key is required.

## Current scope
- Responsive chat interface
- Bangla, English, and bilingual language modes
- Built-in introductory historical Q&A
- Suggested topics and new-conversation control

## Important note
This is an AI-made educational simulation, not Sheikh Mujibur Rahman, not an official representation, and not an authorized source. Answers are a small built-in demo knowledge base, not generated by a live AI model. Verify historical details with reliable books, archives, and other sources.

## Live AI upgrade
A real generative chatbot requires a model provider and a backend endpoint to protect credentials. There is no legitimate unlimited free API guarantee. Do not put private API keys in browser JavaScript.
